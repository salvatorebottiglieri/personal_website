# Project instructions

Before any UI, design, styling, or frontend work in this repo:

1. Read `DESIGN-PRINCIPLES.md`.
2. Read `DESIGN.md` for tokens, component rules, and the slop audit.
3. Treat `DESIGN.md` as the source of truth. If code and `DESIGN.md` disagree,
   fix the code or update `DESIGN.md` deliberately.

The principles are a distilled substitute for the external design skills used
during the 2026-11-09 audit. Do not reinstall those skills for this repo unless
the principles are insufficient.
